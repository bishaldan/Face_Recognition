# Publishing Checklist

## Repository Quality

- Push the current Docker-first implementation
- Add screenshots or a short GIF of enrollment and verification
- Enable GitHub Actions for CI
- Add repository description and website/social preview if available
- Add GitHub topics such as `face-recognition`, `fastapi`, `docker`, `computer-vision`, `onnx`, `opencv`, `biometrics`

## Before Announcing

- Replace default credentials
- Review `.env` handling and secret usage
- Confirm `docker compose up --build -d` still works from scratch
- Confirm README commands match the real workflow
- Add at least one benchmark note or evaluation caveat

## To Earn Trust and Stars

- Show a clean architecture diagram
- Explain why the project exists and who it helps
- Be explicit about privacy and model licensing
- Keep the README skimmable with strong section headings and quick start
- Add screenshots early, because visual proof increases stars and forks

## First Public Release Contents

- `README.md`
- `LICENSE`
- `SECURITY.md`
- `CONTRIBUTING.md`
- `CODE_OF_CONDUCT.md`
- `docs/IMPLEMENTATION_PLAN.md`
- `docs/PUBLISHING_CHECKLIST.md`
