# Code of Conduct

This project aims to be welcoming, practical, and respectful.

## Expected Behavior

- Be kind and constructive.
- Assume good intent, but communicate clearly.
- Focus criticism on code and decisions, not people.
- Share context that helps others learn and contribute.

## Unacceptable Behavior

- Harassment, threats, or intimidation
- Doxxing or sharing private information
- Abusive, insulting, or discriminatory language
- Deliberate disruption of community discussion

## Maintainer Responsibility

Project maintainers may remove comments, issues, pull requests, or contributors that make the project unsafe or hostile.

## Reporting

If someone makes the project unsafe, contact the maintainer privately and include links or screenshots when possible.
